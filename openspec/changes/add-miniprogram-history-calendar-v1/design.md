## 页面结构

微信小程序 tabBar 最多 5 项，现有 5 项已满（总览、情绪资金、行业、题材、我的），所以新增两页不进 tabBar：

| 位置 | 改动 |
|---|---|
| tabBar | 不变 |
| 总览页 | 底部新增"更多数据"区：历史复盘、事件日历两张入口卡片（`navigateTo`），无权限时卡片带锁和所需等级 |
| 我的页 | 新增"全部页面"列表，列出 6 个数据页 |
| 历史复盘（新） | 顶部：交易日、板块类型（行业 / 概念 / 地域）、资金期间（1 / 5 / 20 日）切换。依次为：① 板块结构统计（上涨板块占比、DI 均值、MA20 上方占比中位数、前十成交集中度、资金与涨跌背离占比，带分子分母）；② Open5 统计（覆盖、正向、延续、过度反应占比与分母、数据状态）；③ 板块资金净流入全量排行，不截断，长列表分页加载，单位亿元 |
| 事件日历（新） | 顶部：数据日（前瞻窗口与网页相同，默认 14 天，网页也不提供天数切换）。按日期分组的事件列表：时间、国家、类别、标题、期间、单位、公布状态、前值、公布值、预期值（标注"第三方发布的市场预期，非本平台预测"）、重要性；窗口与"仅宏观日历事件"说明。与网页一致，不显示预期来源字段（旧链路里该字段可能是内部表名） |
| 题材页 | 新增封板时间分布（各题材 × 5 档计数与样本量）；无下钻权限时显示锁定提示 |
| 行业页 | 点击板块进入近 N 日序列（N 取角色可查天数上限，最多 20），无下钻权限时显示锁定提示 |

所有新增内容都沿用小程序现有的 `StateView`：加载中、空数据、部分缺失、出错、无权限五种状态，以及"该日数据暂缺"和"查看最近有数据的交易日"。

## 权限

| 项 | 规则 |
|---|---|
| 页面访问 | 与网页同一份角色权限：权限点 `page.history`、`page.calendar`、`data.detail`（D9 上线后由角色策略生成） |
| 入口 | `client` 只用于审计、路由记录和角色的"可用入口"（`client.mp`：该角色能否登录小程序），不再决定能看哪些页面 |
| 管理后台 | 仍只在网页端提供 |
| 免费用户 | 按其角色权限：看不到的页面显示锁定卡片和开通说明，与网页的锁定预告一致 |

## 与上游切换的顺序（建议）

建议**先补两页**，不等切换。理由：

- 小程序只调本平台接口，不直接访问上游。历史复盘和事件日历的接口与网页完全共用，后端从 review-* 切到事实视图时，网页和小程序一起切，小程序端不需要再改。
- 切换核对比的是本平台接口的对外响应，与入口无关；按页核对一次就同时覆盖网页和小程序。
- 等切完再补，只会让小程序晚上线，换不来任何好处。

资金排行的"分页加载"在小程序端分批渲染同一份全量响应，不另发分页请求，所以切换核对不需要额外样本。

## 实施记录（2026-11-15）

- 小程序编译时，插槽里的表达式会在父页面提前求值：无权限或加载中时 `env` 为空，直接访问 `env.trade_date` 会让整页渲染失败（模拟器走查时发现，表现为空白页）。新页面的插槽内容统一包在 `v-if="env"` 里。
- 缺数据日：`StateView` 新增 `jumpable`，空数据时显示"查看最近有数据的交易日（日期）"，点击后切到该日。

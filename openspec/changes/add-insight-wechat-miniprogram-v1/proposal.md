## Why

用户希望有一个微信小程序专门展示新平台的部分数据，复用同一套后端与权限体系，触达移动端用户。目前尚无小程序资质（AppID/AppSecret），因此本阶段交付范围是"能编译 + 模拟器截图"，真实微信登录与提审上线待资质到位后再做。

## What Changes

- 新增小程序工程（uni-app + Vue 3，与网页同技术栈便于复用），编译目标 `mp-weixin`。
- 页面（部分数据）：首页概览、情绪与资金摘要、行业摘要、题材摘要、我的（登录、兑换邀请码、角色与到期）。
- 复用新平台后端接口与权限裁剪；小程序令牌带 `client=mp`，服务端按 `client.mp` 权限与小程序展示白名单进一步裁剪（不含个股明细、历史深度受限）。
- 微信登录接入点：后端新增 `/auth/wechat`，使用 `code` 换 `openid` 并绑定账号；未配置 AppID/AppSecret 时，生产返回 503，开发环境提供明确标注的本地模拟登录，仅用于演示。
- 账号绑定：小程序首次微信登录得到免费账号；在"我的"页可用网页账号密码绑定，绑定后共用角色与会员期限。
- 用户协议与隐私政策：首次使用弹窗同意（小程序审核硬性要求）。
- 验证：编译产物通过；在模拟器环境渲染并截图；与网页同账号的内容与权限一致。

## Capabilities

### New Capabilities
- `insight-miniprogram`: 小程序页面范围、客户端权限裁剪、微信登录接入点与开发期模拟登录边界。

### Modified Capabilities
（无；依赖 `add-insight-access-control-v1` 的账号与权限）

## Impact

- 代码：新增 `miniprogram/`（uni-app 工程）；后端新增 `/auth/wechat` 与 `client=mp` 裁剪。
- 依赖：uni-app CLI 与 mp-weixin 编译链；模拟器截图依赖 H5 渲染或微信开发者工具（见设计）。
- 不含：微信正式提审与上线、微信支付（本项目不做支付）、订阅消息。

## Context

后端与权限由第三、四期提供。资质缺失，无法在微信侧完成真实授权，也无法提审。当前机器上微信开发者工具是否安装未知。

## Decisions

### D1 技术选型：uni-app + Vue 3
与网页同为 Vue 3，页面逻辑与 API 封装可复用；一套代码可编译为 `mp-weixin`，并可编译 H5 用于无开发者工具时的渲染验证。理由：原生小程序需另起一套语法与工程，维护成本更高。

### D2 "模拟器截图"的实现与边界
- 首选：微信开发者工具命令行打开 `mp-weixin` 产物，在其模拟器中截图（使用测试号 `touristappid`）。
- 备选（开发者工具不可用时）：同一份源码编译 H5，用浏览器按手机宽度渲染截图，并在验收报告中明确标注"H5 渲染，非微信模拟器"。
两种截图在报告中分别标注，不冒充。

### D3 展示范围
小程序展示"部分数据"，由内容注册表增加 `miniprogram` 标记决定：
| 页面 | 内容 |
|---|---|
| 首页概览 | 涨跌家数、成交额、数据日期 |
| 情绪与资金 | ERP 摘要、涨停结构要点 |
| 行业摘要 | 行业涨幅与资金前后若干名（不超出权限的历史天数） |
| 题材摘要 | 涨停数靠前的题材（不含个股明细） |
| 我的 | 登录、兑换邀请码、角色与到期 |
不提供事件日历全量、历史复盘与个股明细。

### D4 客户端令牌与裁剪
微信登录签发的令牌带 `client=mp`；服务端裁剪取"用户角色权限 ∩ 小程序白名单"。网页令牌不能访问小程序专用裁剪，反之亦然。

### D5 微信登录
`POST /auth/wechat {code}` → 服务端用 AppID/AppSecret 调 `jscode2session` 获取 `openid`（不转发 `session_key` 到客户端）→ 查找绑定账号；未绑定则创建免费用户并提示可绑定网页账号。无资质时：生产 503；开发环境 `INSIGHT_ENV=development` 且 `INSIGHT_MP_MOCK_LOGIN=1` 才启用模拟，模拟登录响应显式带 `mock=true`。

### D5b 账号绑定
微信登录产生的账号以 openid 为唯一键；在"我的"页输入网页账号密码完成绑定后合并为同一用户，以网页账号为主（角色、会员期限取二者中较高者）；一个网页账号只能绑定一个 openid，解绑需管理员操作。

### D6 安全
小程序请求同样走签名与限流；包内不含上游 Key 与 AppSecret；域名白名单与 HTTPS 为上线前置，由部署侧提供。

## Risks / Trade-offs

- [无真实微信环境] 无法验证真实登录与审核规则 → 明确标注"未经真实环境验证"，资质到位后补测。
- [H5 与小程序渲染差异] 样式与组件在真机上可能不同 → 仅作为开发期近似，真机验证列为上线前置。
- [类目资质] 股票行情、数据分析类内容在微信小程序属于需要资质的类目，个人主体通常无法通过；上线前需确认主体（企业）与对应类目资质，否则可能无法上线。本阶段只交付工程与截图，此项列为上线首要前置。
- [域名] 小程序请求的域名须为 HTTPS 且已 ICP 备案，并在后台配置合法域名。

## Migration Plan

1. 创建工程与 API 封装；2. 编译 mp-weixin 与 H5；3. 截图；4. 后端 `/auth/wechat` 与 `client=mp` 裁剪；5. 与网页同账号对比权限。
回滚：删除小程序工程与后端新增路由，不影响网页。

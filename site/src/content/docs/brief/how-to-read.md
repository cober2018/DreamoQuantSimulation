> **即将推出**：每日要点还没有上线，下面是它的结构说明。

每条要点包含：

| 字段 | 含义 |
|---|---|
| 句子 | 用固定模板生成的一句事实，不经大模型改写 |
| 类型 | 极值 / 变化 / 连续 / 背离 / 日程 |
| 指标、数值、参照 | 用到的指标、当天的值，以及和什么比（比如「近 60 个交易日的分位」） |
| 强度 | 0–100，表示离常态多远，只用来排序，不代表好坏 |
| 数据日期 | 这条事实对应的交易日 |
| 来源 | 对应的数据页和口径名，点开能落到明细 |
| 性质 | 目前都是「统计」：按规则算出来的事实 |

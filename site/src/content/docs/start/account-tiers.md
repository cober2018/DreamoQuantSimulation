## 一个账号，三处通用

网页、微信小程序（即将推出）和 MCP（即将推出）用同一个账号，不用分别注册。

## 等级

| 等级 | 说明 |
|---|---|
| 免费版 | 网页和微信小程序都能用，可看部分每日要点和公开数据 |
| VIP | 会员档 |
| SVIP | 高一级的会员档 |

各档能看的要点、明细页、历史天数和 MCP 额度还没定，见 [价格与权益](/pricing/)。MCP 只对会员开放。

## 看不到某部分内容时

页面会写明 **以下内容需要更高等级或未在当前等级开放**，并列出是哪几项。其余内容照常显示。

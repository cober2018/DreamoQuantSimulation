## 1. 登录

打开 [dk.dreamotech.cn/login](/login)，用你的账号登录。网页版、微信小程序（即将推出）和 MCP（即将推出）用的是同一个账号。

## 2. 先看数据日期

进入任意数据页，先看标题旁的 **数据日期**。

- 盘后数据按交易日更新，页面默认显示最近一个有数据的交易日。
- 页面标出 **部分内容暂缺** 时，其余内容照常展示；缺了哪些，写在页面底部的 **未提供或不完整的内容** 里。
- 选到没有数据的日期时，页面会说明暂缺，并给出 **查看最近有数据的交易日** 按钮。我们不会悄悄换成别的日期。

## 3. 从总览开始

打开 **市场总览**，看三件事：

1. 主要指数涨跌幅；
2. 上涨和下跌家数，以及上涨占比；
3. 两市成交额。

> **提示**：这些数字只描述今天发生了什么，本身不代表好坏。想知道「和平时比算不算多」，去 **参与度与资金环境** 看分位。

## 4. 和常态比一比

打开 **参与度与资金环境**，看成交额处在近一段时间的哪个分位、主动卖出占比比前一天变了多少。分位和标准分怎么读，见 [要点怎么读](/docs/brief/how-to-read/)。

## 5. 下钻到板块和题材

- **行业比较与轮动**：按涨跌幅、成交额、资金净流入排序，点开单个板块看近期序列。
- **题材与涨跌结构**：看涨停、炸板、跌停的家数和连板梯队。

## 6. 核对口径

每页底部展开 **数据来源与覆盖**，可以看到各部分的数据日、快照时间和覆盖率。指标的定义见 [字段口径表](/docs/reference/fields/)。

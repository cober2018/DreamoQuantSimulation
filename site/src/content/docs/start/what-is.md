## 一句话

知数星耀是一个 A 股盘后数据产品。它按交易日更新六个数据页，只描述市场已经发生的状态，**不预测涨跌，也不给任何操作建议**。

## 你能看到什么

| 数据页 | 回答的问题 |
|---|---|
| 市场总览 | 今天市场发生了什么：指数涨跌、涨跌家数、两市成交额 |
| 参与度与资金环境 | 成交与资金结构相对历史怎样变化：成交额分位、主动卖出占比、股债收益差、衍生品统计、风格强弱 |
| 行业比较与轮动 | 不同板块的表现差异：涨跌幅、成交、换手、资金净流入、扩散度 |
| 题材与涨跌结构 | 涨停、炸板、跌停的分布：连板梯队、题材榜、股票池计数 |
| 历史复盘 | 某一天的数据和历史对比：板块结构统计、开盘五分钟统计、资金净流入排行 |
| 事件日历 | 哪些事件已公布、将公布：宏观数据发布日程、前值与公布值 |

另有 **每日要点**（即将推出）：把六个数据页里当天偏离常态的统计提炼成几条事实，见 [要点怎么读](/docs/brief/how-to-read/)。

## 每个数字都能追到口径

- **数据日期**：每页顶部写明这一页用的是哪个交易日的数据。
- **口径**：指标怎么算、参照什么，写在页面说明和文档的 [字段口径表](/docs/reference/fields/) 里。
- **来源与覆盖**：每页底部的 **数据来源与覆盖** 列出各部分的数据日、覆盖率和缺失说明。

某一天没有数据时，页面会直接说明缺失，**不会拿其他日期的数据代替**。

## 三种用法

| 用法 | 适合 | 状态 |
|---|---|---|
| 网页 | 盘后在电脑上完整复盘 | 可用 |
| 微信小程序 | 在手机上快速看 | 即将推出 |
| MCP | 让你自己的大模型读取数据，自己分析 | 即将推出 |

账号在三处通用。各等级能看的范围见 [价格与权益](/pricing/)。

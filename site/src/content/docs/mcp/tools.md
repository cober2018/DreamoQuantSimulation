> **即将推出**：以下是内部测试版的工具，上线时以服务返回的列表为准。

| 工具 | 作用 |
|---|---|
| `list_datasets` | 列出当前等级可读的数据集和对应工具 |
| `describe_dataset` | 查看一个数据集的字段名称、单位和位置 |
| `get_market_overview` | 市场总览 |
| `get_participation` | 参与度与资金环境 |
| `get_industries` | 各板块的横截面统计 |
| `get_industry_series` | 单个板块近 N 个交易日的序列 |
| `get_themes` | 题材与涨跌结构 |
| `get_history` | 历史复盘：板块结构、资金净流入排行、开盘五分钟统计 |
| `get_calendar` | 事件日历 |

规划中的 `get_daily_brief`（每日要点）和 `get_changes`（与 N 日前比较）会在每日要点上线时加入。

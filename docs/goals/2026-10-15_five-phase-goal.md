## 第二期　数据中台 API 服务（带鉴权）

**目标**：每个看板 1 个 ADS 接口 + 必要的明细接口，全部要求 API Key，Key 只能访问被授权的服务。

**现状**：已有 API Key（sha256 存储、明文只在签发时出现、可吊销），但 `scopes` 未生效，任一有效 Key 可访问全部服务；无过期、无按 Key 限流、无调用审计。

**交付**
1. 按第一期结果补齐/调整服务登记（服务目录按看板分组）。
2. 鉴权增强：
   - Key 绑定可访问的服务或看板清单，越权返回 403；
   - Key 可设过期时间，过期返回 401；
   - 按 Key 限流（每分钟次数可配），超限返回 429；
   - 调用审计：记录 Key、服务、参数摘要、行数、耗时、结果码；
   - 可选来源 IP 白名单；
   - ADS 服务支持 `start_date`/`end_date` 区间查询（现有接口只能取单日，250 日历史要逐日调 250 次，会撞限流）；
   - 持 Key 可查自己被授权的服务目录；支持 Key 轮换（新旧 Key 过渡期并存）。
4. 第一期取数清单中未登记的明细来源，补登记为明细服务。
3. 为新平台签发一把专用 Key（只授权新平台需要的服务），明文只交付到新平台的服务端环境变量。

**验收**

| 测试项 | 通过标准 |
|---|---|
| 无 Key / 错 Key / 吊销 / 过期 | 分别 401 |
| 越权服务 | 403 |
| 超限 | 429 |
| 授权服务 | 200，返回列与白名单一致，分页稳定无重复 |
| 审计 | 每次调用有审计记录，且不含 Key 明文 |
| 生产 | 生产登记完成，新平台专用 Key 实测通过 |

## 第四期　账号、角色权限、邀请码、防逆向

**目标**：清晰的四级角色体系，管理员可自定义；VIP/SVIP 只能通过邀请码兑换；具备基本防逆向和防爬措施。

**角色与权限模型**

| 角色 | 获得方式 | 默认可见（管理员可改） |
|---|---|---|
| 免费用户 | 注册 | 市场总览、事件日历；历史 5 个交易日；同时在线 2 个会话 |
| VIP | 邀请码兑换 | 免费内容 + 参与度与资金环境、行业比较与轮动、题材与涨跌结构；历史 30 日；2 个会话 |
| SVIP | 邀请码兑换 | VIP 内容 + 历史复盘、个股明细；历史 250 日；3 个会话 |
| 管理员 | 系统指定 | 全部 + 管理后台 |

以上为默认种子，管理员可改，也可新建自定义角色（内置四角色不可删）。

- 权限粒度：页面 / 模块 / 历史天数 / 明细数据开关，由"权限点"组成；角色 = 权限点集合。
- 管理员后台可：增删改角色与权限点映射、调整单个用户角色与到期时间、生成/作废邀请码、查看兑换与登录记录。
- 邀请码：指定兑换的角色、有效天数、可用次数、过期时间；兑换后会员到期自动降级为免费。

**登录与安全**
- 注册登录：账号密码（加盐慢哈希存储），预留微信登录（供小程序）；登录失败限次与锁定。
- 会话：短期访问令牌 + 可吊销刷新令牌，服务端校验；登出与修改密码使令牌失效。
- 权限只在服务端裁剪：接口按角色只返回该看到的字段/日期范围；前端隐藏只是体验，不作为安全边界。
- 防逆向/防爬：生产前端代码混淆与去 sourcemap；接口请求签名（时间戳 + 随机数，防重放）；按用户与 IP 限流；异常频率告警与自动封禁；页面与导出数据加用户水印；不在前端存放任何上游 Key。
- 审计：登录、兑换、权限变更、管理操作留痕。

**验收**

| 测试项 | 通过标准 |
|---|---|
| 角色可见性 | 四个角色各登录一次，可见页面与接口返回字段与权限配置一致；越权请求 403 |
| 管理员自定义 | 管理员修改某角色权限后，该角色用户下次请求即生效 |
| 邀请码 | 兑换成功升级；重复/过期/超次数兑换被拒；到期自动降级 |
| 会话安全 | 过期、篡改、已登出令牌被拒；登录失败限次生效 |
| 防爬 | 无签名或重放请求被拒；超限返回 429 |
| 前端 | 生产构建无 sourcemap、代码已混淆、包内无 Key |

## 3. 内容选择规则

每个条目拆到“页面 → 子视图 → 卡片/图表 → 列/字段 → 提示文字 → 筛选排序/下钻”，而不是给整张页面一个总标签。

本文采用三种**内容选择**，不是整改任务状态：

- **保留设计**：把该项列入新产品需求候选；限定为明确的事实/统计展示，具体来源、数据真实性和页面样本继续核对。
- **不迁入**：现有动作、预测性投资选择或其等价输出不进入新产品；原系统保留。
- **待定**：公式/语义/样本不足，暂不放入首版交付清单；不把它判成已违法，也不要求删除原能力。

保留设计不意味着照搬原接口完整响应或原卡片所有内容。原列表若由决策分选出，仅删除“动作”列仍未解决选择语义；候选名单、排序依据和图表提示都要独立核对。
